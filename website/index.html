RETRO TOOLBOX

DOWNLOAD / EXTRACT / PLAY

Turn any HTTP file index into a browsable game library. Queue parallel downloads, extract archives automatically, decompress Switch NSZ files, and browse it all with box art and favorites.

What it does

Everything you need to manage a library

Point it at a server you have the right to use. It handles the rest.

Parallel downloads

Queue as many titles as you want with configurable concurrency and live per-file progress.

Keeps going in the background

Downloads survive backgrounding through a real foreground service on Android.

Auto-extraction

ZIP archives unpack automatically once they land, optionally into a subfolder per game.

NSZ decompression

Switch NSZ archives decompress on device with a bundled Python runtime. No external tools, no desktop round-trip.

Box art & grid view

Browse a cover grid or a compact list, with cached art and a full-screen viewer.

Search & filters

Search by name, filter by region with per-system regex, and see which titles you already have.

Favorites

Star titles, filter down to them, and export or import the list between devices.

Bring your own source

HTML directory listings, JSON APIs, or the Internet Archive metadata API, with bearer, cookie and interactive auth.

Per-console settings

Override the download directory, extraction behavior and filters independently for every system.

Steam shortcut creator

Search the Steam store and drop ready-to-scan .steam shortcut files into any folder.

Tinfoil server

Serve your Switch catalog to Tinfoil over the LAN. It streams and installs straight from the source, with auth injected for you.

Save sync with JKSV

An embedded WebDAV server syncs emulator save exports with JKSV on a Switch, both directions, backed up before every replace.

SMB & FTP

Connect to SMB/CIFS shares to browse and pull files, and use the FTP client or the built-in FTP server to move files over the LAN.

Rar & zip decompress

Extract .rar and .zip archives to a folder. Pick an archive, pick a destination, done.

Collection clean

Dedupe game files, strip region and version tags from names, and sweep out OS junk files — always previewed before it applies.

New catalog source

Add a single console to your catalog from a directory-listing URL or an Internet Archive item.

Servers and tools open from the home screen's grid menu, grouped and out of the way until you need them.

Getting started

Up and running in four steps

No catalog ships with the app. You supply your own source.

Install it

Grab the APK or desktop package from the latest release. On Android you'll need to allow installs from your browser.

Point it at a catalog

Open General Settings → Catalog Source and import a JSON file or load one from a URL. The schema is documented in docs/adding-a-system.md.

Pick your folders

Set a download directory globally or per console, and choose whether archives extract into their own subfolder.

Browse and queue

Search, filter by region, star favorites, and queue as many downloads as your connection can take.

Or build from source

git clone https://github.com/hiitsgabe/retro_toolbox.git
cd retro_toolbox
flutter pub get

# package the embedded Python runtime (once, and after bumping serious_python)
dart run serious_python:main package python_app/ -p Android -r zstandard -r pycryptodome

flutter build apk --release
